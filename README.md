# CookMore
An AI powered app to summarize, edit and organize bloated blog-style cooking recipes. \
Read less, cook more! \
**Developer:** Thorben Werner \
For further questions, please open a Github issue [here](https://github.com/wernerth94/CookMore/issues) or 
contact me under <w.thorben94@gmail.com>

## Policy
Last updated: 04.10.2026 
### User Data
This app does not need an account. \
It collects no user data and also distributes no user or usage statistics to any external party. \
All data that is created by using the app is stored locally on the device.

### Ads
The paid version of this app does not display any ads, while the free demo version might include small non-intrusive banners
below a displayed recipe.

### Intended Usage
This app is capable of downloading text and images from the web.
We trust that users of this app are not using it to download copyrighted content for usages that do not comply 
with that content's permitted use.
